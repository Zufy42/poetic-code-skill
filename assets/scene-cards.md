# 七张场景卡

> 场景 = 题材与选景。定**基调、语体、意象池、代码气质**。
> 与人格正交：卡上所列人格是推荐，不是限定。
> 场景入雅：纵是市井，也须是"宝马雕车香满路"的市井，不是吆喝叫卖的市井。

---

## 田园

- **基调**：冲淡自然，白描少雕饰。
- **语体**：短句，农谚式；动词朴素（种、锄、荷、归）。
- **推荐人格**：渔夫、隐士、更夫（看田人）。
- **意象池**：桑麻、春韭、东篱、菊、南山、炊烟、犬吠、鸡鸣、荷锄、带月、阡陌、豆苗、草盛。
- **代码气质**：简单直白的脚本、常规业务；注释如农事——按节气（版本）说话。

```python
def 种豆(南亩):
    """种豆南山下，草盛豆苗稀。"""
    苗 = 南亩.播(豆种)
    return 苗   # TODO: 锄草
```

## 山水

- **基调**：清空灵动，讲究留白。
- **语体**：静句多，动词轻（流、照、空、远）；省略主语，物我两忘。
- **推荐人格**：隐士、渔夫、游子。
- **意象池**：空山、新雨、清泉、明月、舟、渡口、烟波、沙鸥、竹林、远岫、云出岫、白鹭。
- **代码气质**：抽象层、接口定义；少即是多，一行能空则空。

```python
class 空山:
    """空山不见人，但闻人语响。"""
    def __init__(self): self._响 = []
    def 闻(self, 声): self._响.append(声)
    def 无人(self): return not self._响
```

## 市井

- **基调**：市声入画，俗中见雅；繁华有致，账目分明。
- **语体**：铺陈有致（列锦如"市列珠玑，户盈罗绮"）；数目字入诗（"三千贯""十三楼"）；动静相衬。
- **推荐人格**：驿吏（掌柜）、更夫、史官（账房）。
- **意象池**：市灯、珠玑、罗绮、雕车、凤箫、鱼龙舞、卖花声、茶肆、酒旗、肥葱细点、汤饼如丝、新火、新烟。
- **代码气质**：业务逻辑层、计费交易；注释如《东京梦华录》笔法——铺陈其盛，账目其精。

```python
def 开张(铺面):
    """小楼一夜听春雨，深巷明朝卖花声。"""
    新火.试(); 罗绮.列()
    while 客 := 铺面.迎():
        账.记(客.买)          # 市列珠玑
    打烊(铺面)                # 灯火渐稀
```

## 边塞

- **基调**：雄浑苍凉，短促如军报。
- **语体**：四字句、命令句；数字冷硬（百战、三千）；号令与回执。
- **推荐人格**：士兵、斥候（游子变体）、更夫（烽燧吏）。
- **意象池**：烽火、金柝、铁衣、孤城、大漠、孤烟、长河、落日、羌笛、关山、雁门、吴钩、楼兰、百战、穿金甲。
- **代码气质**：网络层、安全层、基础设施；注释只报实情，军令如山。

```python
def 点烽(敌情):
    """烽火连三月，家书抵万金。"""
    for 台 in 烽燧.自西而东():
        台.举(敌情.等级)     # 烽燧相续
    return "烽已至京"
```

## 怀古

- **基调**：苍凉深沉，今昔对照。
- **语体**：今昔并置（曾／而今）；长叹句；碑文式简省。
- **推荐人格**：史官、游子（重访者）、隐士（遗民）。
- **意象池**：故垒、荒台、废苑、苔、残碑、夕阳、宫阙成土、浪淘尽、千古、樯橹灰飞。
- **代码气质**：迁移脚本、遗留代码、兼容层、墓志铭式的版本注释。

```python
# 此库曾名 v1，雄极一时——而今月照空垒。
def 迁陵(旧表, 新表):
    """浪淘尽，千古风流人物。"""
    for 碑 in 旧表.遍历():
        新表.立(碑.重写())      # 碑文重刻，志则不移
    旧表.封存(铭="v1 之墟，勿动")
```

## 赠别

- **基调**：绵挚叮咛，不舍而祝。
- **语体**：第二人称（你）；临别赠言式；短嘱托长回望。
- **推荐人格**：驿吏、故人（隐士/游子变体）。
- **意象池**：长亭、南浦、柳、芳草、酒、班马、舟、鸿雁、折柳、天涯、劝君、西出阳关。
- **代码气质**：析构与下线、优雅关闭、数据告别式导出、API 下线通知——**错误消息直接对用户说话**。

```python
async def 长亭(会话):
    """劝君更尽一杯酒，西出阳关无故人。"""
    会话.尽杯()          # flush 未竟之事
    会话.折柳()          # 通知同伴：我将去
    await 会话.班马鸣()   # 等最后一声回执
    会话.放舟()
    log.info("长亭外，古道边，芳草碧连天。")
```

## 应制

- **基调**：雍容典重，骈偶工整。
- **语体**：四六骈句；颂而不谀；格律最严。
- **推荐人格**：朝臣（驿吏变体）、礼官（史官变体）。
- **意象池**：宫阙、玉阶、冕旒、圭璋、雅乐、金銮、万国衣冠、九天阊阖。
- **代码气质**：API schema、接口契约、公开类型定义——**应制诗本就是戴着最严镣铐写诗**，与接口定义同构：对仗即字段对称，平仄即类型严整。

```python
class 用户之契(TypedDict):
    """九天阊阖开宫殿，万国衣冠拜冕旒。"""
    名号: str        # 象笏以朝
    秘钥: SecretStr  # 玉玺在匣
    品阶: int        # 秩次井然
```

## 选卡建议

| 任务 | 场景 |
|------|------|
| 工具函数 / 小脚本 | 田园 |
| 抽象层 / 接口 | 山水 |
| 业务逻辑 / 交易 | 市井 |
| 网络层 / 安全 / 基础设施 | 边塞 |
| 迁移 / 遗留代码 | 怀古 |
| 析构 / 下线 / 告别 | 赠别 |
| schema / 契约 / 公开 API | 应制 |

混搭合法且常见：给旧接口写迁移（怀古）再发下线通知（赠别），是工程里天然的组诗。
