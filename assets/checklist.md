# 自检清单

> 淬纹之后对照，逐项过堂。不过关则修；修不了则降档——**宁可不诗，不可不真**。
> 本清单检的是淬纹的结果：铸坯已铸，诗化只置换表层，语义不应变动。
> 入神档不适用本清单（镣铐只余语法一条，改查语法可解析即可），八检全免。

## 八检

### 一、镣铐完好（一票否决；入神档豁免此检，改查语法可解析即可）

- [ ] 程序语义与正确性未因诗化改变（淬纹是置换，铸坯阶段的测试应当同样通过）
- [ ] 语言关键字、dunder、外部 API 契约未被擅改
- [ ] 安全语义（鉴权/加密）保持直白无歧义
- [ ] 若目标语言不支持 Unicode 标识符，已自动降为拼音且可运行

> 不过关怎么办：立即回退命名与结构，诗性让位于正确性。

### 二、意象不越池

- [ ] 所有命名取自宣告的意象群（场景池 + 词典补充）
- [ ] 无 `tmp`、`data`、`handle`、`foo` 等无画面禁字
- [ ] 混搭（如边塞意象入田园）已在宣告中言明

> 不过关怎么办：查词典替换，或将混搭写入宣告使其合法。

### 三、对仗成对

- [ ] 成对概念成对命名：有 `arrive` 必有 `depart`，有 `开城` 必有 `闭城`
- [ ] 律诗体中二联严格对仗（字数相等、词性相对、相邻排版）
- [ ] 对仗双方签名对称（参数数、类型结构）

> 不过关怎么办：缺伴的孤句，要么补对，要么改名去对仗感。

### 四、节内齐整

- [ ] 同一"节"内行长差 ≤ 8 字符
- [ ] 函数体空行分节 2–4 节，每节一意
- [ ] 缩进层级即诗节层级，不乱

> 不过关怎么办：把长行拆行、短行并节；实在不齐的节，考虑俳句化（拆成小函数）。

### 五、诗眼在位

- [ ] 能指出哪一行/节是核心（诗眼）
- [ ] 该行被结构突出：居中、最工整、有点睛注释（`# ← 诗眼` 或意会式）
- [ ] 周围代码为之烘托而非喧宾夺主

> 不过关怎么办：重构排版，让主旨行获得视觉焦点；找不到诗眼说明函数职责过多，先拆分。

### 六、人称一致

- [ ] 全模块同一抒情人格，无穿帮（渔夫忽变史官）
- [ ] 人称（我/你）全文一致
- [ ] 抒怀密度克制：每三行注释至多一句

> 不过关怎么办：通读注释统一口吻；删掉抢戏的抒怀句。

### 七、宣告在案

- [ ] 选配宣告已写出：场景 × 人格 × 主意象 × 档位 × 诗体
- [ ] 律诗体 docstring 是真律诗（八句一韵、中二联对仗），歌行体各章有过变
- [ ] 实际代码与宣告相符（宣告了律诗体就是八成员四联）
- [ ] 自定义词牌已在 docstring 明写词谱

> 不过关怎么办：补宣告，或按宣告修码——二者取一，不可含糊。

### 八、题句合律（评诗最严的一条）

- [ ] 自撰句均为完整五/七言律联（上句仄收下句平收）或词牌句式（注源）
- [ ] 无单句自造、无白描短句混入注释
- [ ] 所引/所撰诗句后无解说尾巴
- [ ] 句意与代码功能相涉，无无关风景
- [ ] 自撰联已过 `python scripts/pingze.py "上句，下句"`（节奏点交替、上仄收下平收）

> 不过关怎么办：按 cipai.md 律联速查重写；平仄卡壳跑校验器逐字定位；实在写不出则引真诗或留白（`python scripts/inspire.py` 可抽签）。
