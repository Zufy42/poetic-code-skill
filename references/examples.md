# 示例集

> 同一功能的铸坯与三档淬纹：**带指数退避的请求重试**。
> 按 SKILL 铁律：先铸坯（正常写），后淬纹（诗化置换）。
> 选配：山水场景 × 渔夫人格 × 舟网意象。
> 所有版本均可运行（Python 3.10+）。

---

## 〇、铸坯（正常版——诗化的前身，工程最优解）

```python
import time

def fetch_with_retry(fetch, max_retries=5, base_delay=1):
    for attempt in range(max_retries):
        try:
            return fetch()
        except Exception:
            if attempt == max_retries - 1:
                raise
            time.sleep(base_delay * 2 ** attempt)
```

## 一、发轫档（ASCII 命名，注释克制，可入工程）

```python
import time

def chuidiao(fish, ci_wang=5, deng_yi=1):
    """带指数退避的重试：失败则等待后重试，等待逐次翻倍。"""
    for jing in range(ci_wang):
        try:
            return fish()
        except Lang:                    # lang = 风浪
            if jing == ci_wang - 1:
                raise
            time.sleep(deng_yi * 2 ** jing)   # ← 诗眼
```

> 发轱档要点：拼音命名（`chuidiao` 垂钓）、意象只入注释、异常名尚可拟象（`Lang`）但保持可查——lint 不恼，同事不骂。

## 二、精诣档（默认：汉字命名，人格入注）

```python
import time

class 风浪(Exception):
    """道是无晴却有晴。"""

def 垂钓(撒竿, 至多=5, 静候=1):
    """青箬笠，绿蓑衣，斜风细雨不须归。"""
    for 静水 in range(至多):
        try:
            return 撒竿()
        except 风浪:
            if 静水 == 至多 - 1:
                raise
            time.sleep(静候 * 2 ** 静水)   # ← 诗眼
```

> 精诣档要点：汉字命名成体系（垂钓/撒竿/风浪/静水——同一意象池）；注释有身份（渔夫）；分节与行长开始讲究（起-承-转）。

## 三、冠古档（词牌 docstring，文言消息）

```python
import time

class 风浪(Exception):
    """风波恶。"""

def 垂钓(撒竿, 至多=5, 静候=1):
    """调寄《渔家傲》——
    一棹归来天欲暮，风前不问鱼多处。
    网得空时眠得去，君莫诉：明朝更有明朝雨。"""

    for 静水 in range(至多):           # 上阕
        try:
            return 撒竿()
        except 风浪 as 浪:             # 下阕
            if 静水 == 至多 - 1:
                raise TimeoutError(
                    f"五撒网空，收竿。末浪：{浪}"
                ) from 浪
            time.sleep(静候 * 2 ** 静水)  # 静水无波，一倍一歇
```

> 冠古档要点：docstring 调寄词牌（自度曲亦可，但需标注）；错误消息文言短句 + 携带事实（末浪）；韵脚意识（暮/处/去/诉/雨——不苛求全押，有韵即佳）。

## 附：赠别场景一例（精诣档，展示场景卡的差异）

**优雅关闭**——选配：赠别 × 驿吏 × 长亭意象：

```python
async def 长亭(客栈: Server):
    """劝君更尽一杯酒，西出阳关无故人。"""
    客栈.停迎新客()        # 闭门
    await 客栈.尽杯()      # 尽杯
    客栈.折柳(同伴们)      # 折柳
    await 客栈.班马鸣()    # 班马鸣
    客栈.放舟()
    log.info("长亭外，古道边，芳草碧连天。")   # 尾联
```

对比可见：同为精诣档，场景换了，**语体、意象池、代码气质**全换——这就是场景卡的作用。

## 自撰联示范（新语体纪律的首选）

> 语体纪律三层：**自撰合律句 > 引真诗 > 留白**。自撰句必须完整律联（上仄收下平收）或词牌句式。
> 歌行体 demo（限流/重试/降级客户端）三章章首，均为自撰七言联：

```python
# ── 第一章 金柝 · 边塞韵 ──
# 更鼓有期催过客，烽烟无警度流年。
#   限流：更鼓有期＝令牌按时补充；催过客＝放行请求
#   （此二行解说仅文档示范，实码中不写——格律自达意）

# ── 第二章 垂纶 · 山水韵 ──
# 空网不辞重下钓，斜风偏与慢收纶。
#   重试：空网再钓＝失败重试；慢收纶＝指数退避

# ── 第三章 锦囊 · 赠别韵 ──
# 此路关山行不得，锦囊分我一枝春。
#   降级：行不得＝主路失败；一枝春＝fallback
#   （化用鹧鸪"行不得也哥哥"与陆凯"聊赠一枝春"）
```

> 三联自检：均为上句仄收（客／钓／得）下句平收（年／纶／春），二四六平仄交替——合律。
> 典故入联则意自深：`行不得`三字自带鹧鸪啼声，胜过十行解说。

## 诗眼练习

回到重试四版：哪一行是“诗眼”？——`time.sleep(静候 * 2 ** 静水)`，指数退避的本体。精诣/冠古版都让此行独占一“节”且以注释点睛（`# ← 诗眼`）。淬纹时若找不到诗眼，说明铸坯阶段结构未为主旨服务——回到第一阶段重排，不要在诗化层硬凑。
