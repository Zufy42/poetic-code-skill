> 依据龙榆生《唐宋词格律》（上海古籍出版社）整理，二十调。

## 用法三则

1. **摘句**：不必成篇。取词牌中一两个句式填入注释即可，如按《长相思》"中仄平平中仄平"填单句。摘句注明词牌来源：`# （长相思句）汴水流，泗水流`。
2. **成篇**：docstring 全填一阕，须守全谱句数字数（韵与平仄从宽：韵位必守，平仄二四六分明、一三五从宽）。标注：`调寄《渔歌子》`。
3. **自度曲**：无合适词牌时自造句式，须在 docstring 明写谱（几段、各段句式），谱即承诺。

## 律联速查（五七言自撰句的格式底线）

自撰律联最低要求（对仗不强求）：

- **上句仄收，下句平收**（铁律）
- 五言：`中仄平平仄，平平仄仄平` 或 `中平平仄仄，中仄仄平平`
- 七言：五言前加相反两字，如 `中平中仄平平仄，中仄平平仄仄平`
- 句内节奏点（五言二四、七言二四六）平仄交替
- 句意须与代码功能相涉（咏物传统），不咏无关风景

不合格示例（自造散句，无形式）：
```
# 风未起，不下竿。        ← 三三句非词牌句式，非律联，蹩脚
```
合格示例（七言律联，上仄收下平收）：
```
# 更鼓有期催过客，烽烟无警度流年。
```

自检命令（入声已内置，多音字标"中"）：
```bash
python scripts/pingze.py "更鼓有期催过客，烽烟无警度流年"
```
