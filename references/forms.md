# 六体：结构规范

> 档位管诗化多深，诗体管格律多严。六体供发轫/精诣/冠古三档自由组合；入神档豁免代码形式，不用诗体。
> 默认自由体。所有示例均为精诣档（汉字命名），发轫档替换为拼音/英译即可。

---

## 一、俳句体

**约束**：函数体 ≤ 3 行；函数名 ≤ 3 字；一事一函数，全函数如一首俳句。

适合：工具函数、lambda 心境。

```python
def 筛(n: int) -> list[int]:
    """千淘万漉虽辛苦，吹尽狂沙始到金。"""
    留 = list(range(2, n + 1))
    for 眼 in range(2, int(n**0.5) + 1):
        留 = [数 for 数 in 留 if 数 == 眼 or 数 % 眼]   # 吹尽狂沙 ← 诗眼
    return 留
```

> 注：俳句体允许"骨架行"（签名、docstring、return）不计入 3 行；**诗行**——真正干活的行——不得超过 3。本例诗行恰为三：留、筛、漏。初稿曾为凑行数砍去标记循环，被自检"镣铐完好"一票否决——前车之鉴，写进此注。

## 二、绝句体

**约束**：模块恰好 4 个主函数，按**起承转合**排列：

| 联 | 职 | 例 |
|----|----|----|
| 起 | 事之始 | `种豆()` |
| 承 | 日常之劳 | `荷锄()` |
| 转 | 去芜存菁，**诗眼在此** | `理荒秽()` |
| 合 | 功成而返 | `带月归()` |

适合：小脚本、单文件程序。

```python
def 种豆(南亩): ...        # 起
def 荷锄(田亩): ...        # 承
def 理荒秽(豆田): ...      # 转（诗眼）
def 带月归(归途): ...      # 合
```

> 四函数取陶渊明《归园田居》：种豆南山下，草盛豆苗稀；晨兴理荒秽，带月荷锄归。

## 三、律诗体

**约束：类即一首真律诗。**

1. **docstring 是一首真正的五律或七律**——八句、一韵到底（标注用韵：平水韵或新韵）、颔联颈联对仗。诗**咏本类职能**（咏物诗传统），不是贴无关风景。
2. **8 个成员（方法/属性）与八句一一对应**：首联（1–2）启、颔联（3–4）与颈联（5–6）各为一对、尾联（7–8）收。
3. **成员注释直接引 docstring 中对应的那句原诗**，不作解说——诗码互文，注即是诗。
4. 对仗落在代码上：颔联、颈联的成员**成对命名、签名对称、相邻排版**。
5. 宽律/严律自选并在 docstring 标注：宽律要求对仗+押韵；严律再核平仄（一三五不论，二四六分明）。
6. **苦吟即此为止**——推敲只限这八句诗，一次成稿；成员映射与代码逻辑不享受苦吟。

示例——内存任务队列（七律·平水韵七阳，宽律）：

```python
class 孤驿:
    """咏内存任务队列（七律·七阳）——
    孤驿灯深夜未央，星河垂户雁成行。
    书来每趁三更柝，马去频嘶十里霜。
    路远偶迷重问渡，更长不误再添香。
    天明各自登程去，折柳一枝封旧箱。"""

    def __init__(self, 驿丞=None):          # 孤驿灯深夜未央
        self.鸿雁 = deque()                  # 星河垂户雁成行
        self.柝声 = 驿丞 or 更夫()

    def 递书(self, 帛书, 至更=3):            # 书来每趁三更柝
        self.鸿雁.append((帛书, 至更))
        self.柝声.敲()

    def 驰驿(self):                          # 马去频嘶十里霜
        while self.鸿雁:
            书, 至更 = self.鸿雁.popleft()
            yield from self.问渡(书, 至更)

    def 问渡(self, 书, 至更):                # 路远偶迷重问渡
        for 迷 in range(至更):
            try: return 书()
            except 风浪: self.添香(迷)

    def 添香(self, 迷):                      # 更长不误再添香
        time.sleep(2 ** 迷)                  # ← 诗眼

    def 登程(self):                          # 天明各自登程去
        self.驰驿毕 = True

    def 封箱(self):                          # 折柳一枝封旧箱
        while self.鸿雁:
            self.驰驿()
```

> 对仗自检：颔联 `递书/驰驿`（动宾对动宾，入/出对称）、颈联 `问渡/添香`（动宾对动宾，失/待对称）——合律。八成员注释皆引原句，无一句自造——**注即是诗，不注即留白**。

## 四、歌行体

**约束：分章而作，章可换韵。**

复杂度不是一首律诗装得下的（多文件、>60 行、成员远逾八），用歌行——歌行是叙事的长歌（《春江花月夜》《琵琶行》《长恨歌》），篇幅自由，**转韵换意**。

1. **章法**：代码分**章**，一章 = 一个文件 / 类群 / 子模块。章有**章题**，二字为佳（`惊鸿`、`转蓬`、`折柳`），标在文件头或分节注释。
2. **换韵**：章与章可换韵——换韵即换**意象池、场景、甚至人格**（第一章边塞鸿雁、第二章市井算盘）。换韵处必须有**过变**：一段明确的桥接代码（适配层、接口转换），如词之换头。
3. **叙事流**：主流程如叙事诗推进——受事（起）、铺陈（承）、波澜（转：异常与恢复是歌行的跌宕处）、收束（合）。
4. **复沓**：歌行叠唱（"春江潮水连海平"式回环）对应重复结构——鼓励保留重复而非抽象，与律诗复沓律同理。
5. **章首题句引完整成句或成联**（自撰律联或真诗均可），全章注释围绕它展开；章与章的诗句不必同韵——这正是歌行与律诗的分野。
6. **苦吟上限 = 联数**——每章一联，逐联推敲，联成即止；不为一句久留。

骨架示例（一个三层的消息处理系统）：

```python
# ── 第一章 鸿雁 · 边塞韵 ──────────────
# 朔气传金柝，寒光照铁衣
# 雁书所从来
class 鸿雁: ...          # 入队、出队（本章成员不拘对仗）

# ── 过变 · 渡口 ─────────────────────
# 边声换市声
def 渡口(雁书) -> 算珠:
    ...

# ── 第二章 算盘 · 市井韵 ──────────────
# 市列珠玑，户盈罗绮
class 算盘: ...          # 计价、记账

# ── 第三章 长亭 · 赠别韵 ──────────────
# 劝君更尽一杯酒，西出阳关无故人
class 长亭: ...          # 优雅关闭、通知、归档
```

> 歌行体的自由是章内的自由：章内不必对仗、不拘行数；章间的纪律是**过变必须显式存在**——没有渡口，就不许从边塞直接走进市井。

## 五、词牌体

**约束**：给定结构骨架（“词牌”），往里填实现——**按谱填词，不增不减**。常用谱见 [cipai.md](cipai.md)（二十调全谱），速查：

**《如梦令》谱**（三段式流程）：
```
试（试探/校验）→ 问（查询/求索）→ 知（知晓/返回）
```

**《水调歌头》谱**（上下双阕）：
```
上阕：集配置、收上下文（问天）
下阕：执行变换、输出结果（对人）
```

**《声声慢》谱**（寻寻觅觅式逐层检索）：
```
寻（一级查找）→ 觅（二级回退）→ 冷冷清清（兜底空态）
```

示例（按《如梦令》谱写的配置读取器）：

```python
def 取配置(名: str) -> str:
    """试问卷帘人，却道海棠依旧。"""
    试 = os.environ.get(名)
    问 = 试 or 读配置文件(名)
    知 = 问 or 默认值[名]
    return 知
```

> 自定义词牌合法：先在模块 docstring 中**明写词谱**（几段、各段何职），再按谱填码。谱是承诺，填完不可增删段。

## 六、自由体

**约束**：无结构约束，只保留命名取象与人格抒情。

适合：默认兜底、既有代码的诗化重构（改造成本最低）。

```python
def 等风起(旗语, 至多=5):
    """青箬笠，绿蓑衣，斜风细雨不须归。"""
    for 静 in range(至多):
        if 旗语.有风():
            return 旗语.风向()
        time.sleep(静)
    raise TimeoutError("五竿皆空，归。")
```

## 六体速记

| 体 | 一句话 |
|----|--------|
| 俳句 | 三行之内，一字千金 |
| 绝句 | 四函数，起承转合 |
| 律诗 | 类即一首真律诗，八成员配八句，注引原句 |
| 歌行 | 分章换韵，过变搭桥，长篇叙事 |
| 词牌 | 按谱填码，不增不减 |
| 自由 | 无格律，有意象人格即可 |
