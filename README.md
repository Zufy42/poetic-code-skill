# poetic-code · 诗化的代码

> 诗是戴着镣铐跳舞。代码的镣铐是编译、运行与正确性——诗化永不在镣铐之外起舞。

一个 [Agent Skills](https://agentskills.io) 格式的技能包：教 AI **先写正常的代码，再为它披上诗的纹样**。

它不是代码生成器，也不是风格转换玩具那么简单——它把中国古典诗学的一整套资产（场景、意象、人格、格律、词牌、平仄）翻译成了可操作的编程工作流。

## 这是什么

给 AI 一个编程任务，它通常写出"正确的代码"。装上本技能后，它可以写出**既正确、又合律**的代码：变量取自意象，结构暗合格律，注释与错误消息由一位有名字、有来历的抒情者说出。

一段【精诣档】的埃氏筛，长这样：

```python
def 埃氏筛(上限: int) -> list[int]:
    """调寄《如梦令》——让数像雪一样落下来，
    穿过筛眼的都化了，留在筛上的，是数中的君子。"""

    未化 = [True] * (上限 + 1)        # 初雪覆地，皆白
    未化[0] = 未化[1] = False         # 零与一，不入门墙

    for 筛眼 in range(2, int(上限**0.5) + 1):
        if 未化[筛眼]:                 # ← 诗眼所在
            for 雪痕 in range(筛眼*筛眼, 上限+1, 筛眼):
                未化[雪痕] = False     # 筛眼所过，积雪尽融

    return [数 for 数 in range(上限+1) if 未化[数]]
```

可运行。这不是比喻，是产物。

## 四档：诗化多深

| 档位 | 标识符 | 注释与消息 | 定位 |
|------|--------|-----------|------|
| **发轫** | 拼音/英文（ASCII） | 中文，有意象但克制 | 可入工程，不违 lint |
| **精诣**（默认） | 直书汉字 | 中文，有人称语气 | 个人项目、玩具 |
| **冠古** | 直书汉字 | 成诗，错误消息文言短句 | 纯艺术 |
| **入神** | 直书汉字 | 诗行本体 | **纯诗实验**：唯一镣铐是语法，功能可偏离需求，代码形式（换行/封装/风格）全部让位于诗 |

## 六体：格律多严

| 诗体 | 结构约束 |
|------|---------|
| 俳句体 | 函数 ≤3 行，一事一函数 |
| 绝句体 | 模块恰 4 个主函数，起承转合 |
| 律诗体 | 类即一首真律诗：8 成员配八句，中二联对仗 |
| 歌行体 | 分章换韵，长篇叙事（复杂模块） |
| 词牌体 | 按谱填码，不增不减 |
| 自由体 | 只保命名与人格（默认） |

## 三资产：自由组合

- **场景**（七卡）：田园 / 山水 / 市井 / 边塞 / 怀古 / 赠别 / 应制——定基调、语体、意象池
- **意象**（120+ 条词典）：天象/地理/植物/动物/器物/人事典故六部，每条附代码映射（鸿雁→消息队列、白衣苍狗→竞态、鸡肋→deprecated、执牛耳→leader election……）
- **人格**（八卡）：士兵/渔夫/更夫/史官/医者/驿吏/游子/隐士——附任务现写的人物小传制度

一句选配宣告定下全篇：*"这是一首边塞诗，以斥候的口吻，取鸿雁为象。精诣档，律诗体。"*

## 内置工具

| 脚本 | 用途 |
|------|------|
| `scripts/inspire.py` | 灵感触发器：今日诗词 API 随机抽一句真诗定调（免 key，离线降级） |
| `scripts/pingze.py` | 平仄校验器：逐字标注律联，检查节奏点交替与联对（内置平水韵入声字表 735 字，据 charlesix59/chinese_word_rhyme） |

```bash
python scripts/pingze.py "更鼓有期催过客，烽烟无警度流年"
# 更鼓有期催过客  仄仄仄平平中仄  节奏点（仄平中）✓交替
# 烽烟无警度流年  平平平仄仄平平  节奏点（平仄平）✓交替
#   —— ✓ 合律
```

## 安装

方式一（pi 用户，一条命令）：

```bash
pi install git:github.com/zfyyy/poetic-code-skill
```

方式二（手动，其他 Agent Skills 兼容环境）：

```bash
git clone https://github.com/zfyyy/poetic-code-skill.git ~/.pi/agent/skills/poetic-code
```

方式三（临时体验，不安装）：

```bash
pi --skill <本仓库路径> "用精诣档写一个心跳检测模块"
```

## 使用

装好后自然生效。触发方式任选：

- 「用诗化风格重构这段代码」（默认精诣档）
- 「用律诗体设计一个缓存类」
- 「以边塞风写这个网络模块，用士兵的口吻」
- 「入神档：写一个优雅关闭」（最高档，须显式指定）

完整规则见 [SKILL.md](SKILL.md)，词谱见 [references/cipai.md](references/cipai.md)。

## 设计原则

1. **先正常，后诗化**——铸坯（工程最优解）→ 淬纹（表层置换）→ 试锋（自检）。诗化永不参与设计决策，因此思考更快，也永不破坏正确性
2. **戴着镣铐跳舞**——语言关键字、外部 API 契约、安全语义永不诗化；测试该过还是过
3. **无形式不成诗**——注释里的诗句必须是自撰合律句（内置平仄校验器）或真诗引文，白描与仿古散句一律禁绝
4. **入神是唯一的例外**——最高档只留语法一条镣铐，且须用户显式指定
